# Dashboard (Explorer v0)

React 19 + TypeScript + Vite, Tailwind CSS v4, shadcn/ui (Base UI), TanStack Query, Zustand, React Router.

## Develop

```sh
npm install
npm run dev          # http://localhost:5173, /api proxied to https://server.aegonassett.com
```

Against a Go API running locally instead:

```sh
API_PROXY_TARGET=http://localhost:8080 npm run dev
```

## Build and deploy

```sh
npm run build        # outputs dist/
```

Production is served by the same IIS site as the API (`https://server.aegonassett.com/`), so there is no CORS.
`backend/deploy/iis/setup.ps1` copies `web/dist` into the site on every run. For a dashboard-only update, copying `dist\*` into `C:\relaya\site` is enough; no service restart is needed.

## Layout

| Path | What |
|---|---|
| `src/lib/api.ts` | fetch wrapper; bearer token; 401 signs you out |
| `src/lib/queries.ts` | all TanStack Query hooks, one per API call |
| `src/lib/auth.ts` | session + selected org (Zustand, persisted to localStorage) |
| `src/pages/` | Events (Explorer), Webhooks, Projects, Members, API keys, Audit log, auth |
| `src/components/ui/` | generated by shadcn; add more with `npx shadcn@latest add <name>` |

Known follow-ups: move the session from localStorage to an httpOnly cookie before public launch; code-split the bundle (currently ~560 kB, 178 kB gzipped).
